1. La carpeta Calibrar contiene los documentos necesarios para la calibración, específicamente los datos de simulación, los tiempos perdidos, la heuristica y el tuner que
permite la calibración.
2. La carpeta resultados contiene algunos resultados que hemos obtenido, sobretodo en Excel por ahora. Con estos datos vimos que calibración fue mejor para la operación
histórica
3. El archivo baseline.py es un archivo que me permite procesar los datos y entregarme un excel con la operación y decisiones históricas
4. El archivo heuristica.py contiene la heuristica desarrollada.
5. El archivo run.py permite procesar los datos pero tomando la decisión a base de la heuristica propuesta.
